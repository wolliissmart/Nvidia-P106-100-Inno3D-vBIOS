# Nvidia-P106-100-Inno3D-vBIOS
In this repository, you will find the dump from the vBIOS of an Inno3D P106-100 mining-GPU.

I got the dump with the software "nvflashk", using two different cards from the same revison. The exact model code is: MN106F-5SDN-N5G. My two cards are from 2017. The SHA256 Hash is "4F6978967EF98F73795B55C2C160CDF846AA21323CFFDDB211C4061B6CA515CD".
